| 层面 | 精度状态 |

## 1. 程序架构与约定(精度讨论的前提)

```
CST 翼型族(2mm TE 硬约束) → Foil2D(线性涡强ψ-Dirichlet面板 + Thwaites/Michel/Head
积分BL + Kármán-Tsien压缩性) → 极线表 Cl/Cd(α,Re,M)
→ RotorSolver v3:自由尾迹(PIPC预测-校正+松弛) + 2D表叶素载荷
   诱导速度 = 全部尾迹涡段+他叶附着涡的精确有限段 Biot-Savart(Vatistas核,解析涡核生长)
→ 功率账本 v2:P_ind = (P_axial + P_swirl)·κ_cal + P_prof
   P_axial = B·Σ T_i·vi_i(推力加权盘均入流)
   P_swirl = 盘面切向诱导的 KE 通量(保守侧)
   P_prof  = 2D 表型阻(设计口径 ×1.15)
→ 配平(集体距割线/二分至 T=200 kgf) → 优化目标 = 配平功率
```

系数约定(2026-10-24 修复后):`CT = T/(ρΩ²πR⁴)`,`CQ = Q/(ρΩ²πR⁵)`,
`FM = P_ideal/P = CT^1.5/(√2·CQ)`(R 任意时均精确成立,已数值验证)。
**无任何 BEMT/动量理论入流**:全部诱导速度来自自由尾迹涡系直接积分(红线自证)。

## 2. 数值精度(确定性)

- 同配置(交付叶片,hi-fi 档 dψ7.5°/6圈,冻结协议)独立重跑两次:
  **FM = 0.8375 vs 0.8375(|dFM|=0.0000)**,配平距逐位一致(17.834°)。
  → 求解器完全确定性,历史"±0.02 复现噪声"已查明为 finalize.py 的 R 因子 bug(§6),非数值噪声。
- 收敛判据:Γ 最大变化 <3e-4 相对量;外迭代 22(fast)/26(hifi)/34(delivery)。
- 已知数值实践:诱导速度限幅(0.25·ΩR,仅作用于诱导分量)、展向平滑、欠松弛 0.35——
  均为稳定性措施,对收敛解的影响包含在基准验证数字内(即已被实验校准吸收)。

## 3. 2D 翼型链精度(Foil2D)

### 3.1 升力(可信)
| 对比项 | 自研 | NFool(mfoil 体系) | 实验 |
|---|---|---|---|
| Cl_α(NACA0012,Re 1.2e6,α0-5°) | 0.1101/deg | 0.1088/deg | 0.109(Ladson) |
| 无粘 Cl 全域 α0-16°(M0 / M0.3) | — | 差 **−0.8~−0.9%** | — |
| 粘性 Cl α≤5° | — | 差 **+0.9~+2.2%** | — |
| Cp_min(0°/5°,Re 6e6) | −0.41/−1.99 | — | −0.42/−2.0 |

### 3.2 阻力(系统性偏低,已知)
- 平板对比(Re 6e6):自研 Cd 0.0050-0.0054 vs 实验 0.0058-0.0065 → **低 12~18%**
  (简化 BL 层级的文献预期内)。
- vs NFool 粘性(α≤5°):低 5~11%。
- **处置**:设计口径内置 Cd×1.15 硬修正;基准矩阵另跑原始表以隔离该贡献。
- 残余风险:α→失速区(压力拖尾)低估可能超过 15%——这是 C-T θ12 工况 CQm −20% 的
  主要嫌疑人之一。

### 3.3 交叉验证的边界
- NFool 本机环境(Windows/py3.14/numba0.68)**粘性 α≥6° Newton 不收敛**(fork 缺陷,
  conv=False 可检测),故粘性交叉验证仅覆盖 α≤5°;α≥6° 依赖无粘对比 + 3D 基准仲裁。
- **低 Re(4-8×10⁴,DJI regime)层流分离泡**是自研 BL 最弱区——DJI 案例的大偏差
  (§5)主要归因于此。设计点 Re 4.5e5~2.4e6 不受影响。

**核心解读**:
1. **推力系数在核心域达标**(±10% 内;φ=1.2 定标后);
2. **配平扭矩全家族系统性低估 15~25%** —— 定向一致的非随机偏差;

   排除尾迹分辨率 → 结构性模型偏差(Cd 失速区低估 + 旋涡/收缩 KE 欠计);
4. Martin-Tung 的 +1947% 是真实的域外灾难(微型高实度+根涡螺距<涡核),如实记录不掩盖。

## 5. 功率账本与 FM 口径

交付叶片(D=2.08m/T=200kgf/B=2,hi-fi 档)在**设计口径**(φ1.2+Cd×1.15)下的账本:

| 项 | 数值 | 占总功率 |
|---|---|---|
| P_axial(推力×盘均入流) | 34.42 kW | 93.1% |
| P_swirl(旋涡 KE,盘面值) | 0.18 kW | 0.5% |
| P_nonuniform(账本单列,已含于 P_axial) | +0.03 kW | 0.1% |
| P_prof(×1.15 后) | 2.46 kW | 6.7% |

**FM 阶梯**(对 κ_cal 的敏感度即 FM 的口径不确定度):

| κ_cal | 1.00 | 1.05 | 1.10 | 1.15 | 1.18 | 1.20 |
|---|---|---|---|---|---|---|
| FM | 0.821 | 0.785 | **0.751** | 0.720 | 0.703 | **0.692** |

- 尾迹自身非理想度 κ_raw = vi_disk/vi_ideal = 1.14~1.18(2 叶桨教科书水平,深浅尾迹一致);
- P_swirl 取盘面切向分量,远场收缩会加强(×~2)——保守侧,若按远场计 +0.5~1pp;
- **报告规范**:FM 必须同时给出 κ=1.0(物理口径)、κ=1.1(计划 Gate C 悲观口径)、
  κ=1.2(定标口径)三个数,附本阶梯。

## 7. 适用域与外推风险(当前最大不确定度来源)

| 维度 | 已验证域 | 设计点 | 风险 |
|---|---|---|---|
| 桨叶数/实度 | B=2,σ 0.076-0.191 | B=2,σ 0.178 | ✅ 域内 |
| 推力系数 | CT 0.002-0.012 | **CT 0.0194** | ⚠️ **外推 2.2~4×**(基准包络外) |
| 雷诺数 | 3e5-3e6 良好;4-8e4 差 | 4.5e5-2.4e6 | ✅ 域内 |
| 桨尖马赫 | <0.6(极线表上限) | 0.459 | ✅ 域内(0.6-0.72 工况已弃) |
| 失速裕度 | — | 平均 Cl≈0.65,α_eff≤7.2° | ✅ 大裕度 |

**外推的物理依据**:κ_raw 在 C-T 的 CT 0.0023-0.0098 范围内保持 1.18±0.01(尾迹加深
收敛),设计点叶素-尾迹耦合结构与 C-T 同类(2叶/中等载荷),故诱导侧按 κ_cal 平移外推
是当前最优估计;但 **CQm 缺口随 CT 的缓增趋势(−10%→−20%)若延续到 CT=0.0194,
真实 κ_cal 可能高于 1.20** —— 这是 FM 报告必须带不确定度带的原因。

## 9. 结论

1. **可信**:推力/载荷分布(核心域 ±10%)、升力线(±2%)、数值确定性(0.0000);
2. **已知偏差**:功率/扭矩系统性乐观 15~20% → κ_cal=1.20 定标后 ±8% 内(来源已记录,
   可复算);FM 绝对值必须带口径阶梯报告;
3. **最大风险**:设计点 CT 超基准包络 2.2~4× 的外推,以及失速邻区 Cd 模型;
4. **建议后续**(按优先级):① NFool 修复后补 α≥6° 粘性交叉验证(或换 XFOIL);
   ② 失速区 2D Cd 用实验极线补充校准;③ CMA-ES 个体级并行(≈×8 提速);
   ④ 若要压缩 κ_cal:远场旋涡 KE 按收缩远场采样(+1pp)、涡核生长重标。
